Bitbox Micro Themes

Five themes beside Stock, and a maker for your own. Every colour on 1010's screens comes from one 34-entry palette, so a theme is a new set of those 34 colours. Each theme recolours the palette family by family: the pink selection, the cyan accent, the grey cells, the dark backgrounds, the status colours.

Previews of the Pads and Settings screens, drawn from the manual's screenshots. On the module each colour also turns up on the other screens, such as the waveform view and the LFO and envelope graphs.

The themes

Make your own

Start from any theme, change what you like, and download or copy the file. Each figure is a contrast ratio for the pair that matters most for that colour (WCAG's measure: 4.5:1 is the usual minimum for small text). Green is comfortable, amber readable but low, red hard to read on the module's small screen. Stock itself falls short in two places: white text on its pink selection, and its cyan bar on that pink.

Putting it on the module

  1. Download the file, or copy it into a text file, and save it as theme.tml at the top of the card, next to settings.tml. It is the same XML style the module already reads.
  2. On the module, open TOOLS > Settings and set Theme to Custom. If it is set to Custom already, turn Theme to another and back to Custom: the module reads the file again each time Custom is chosen.
  3. If there is no theme.tml yet, choosing Custom writes one for you, filled with the theme on screen, so you always start from a working file.
  4. A colour that is missing or mistyped shows as Stock's, so a slip can never leave the screen unreadable.

In Custom the CPU bar follows your colours too: its green, amber and red take the theme's green, yellow and red. The built-in themes keep the stock green, amber and red, and the pop-ups stay white on black in every theme, so they always stand out.
